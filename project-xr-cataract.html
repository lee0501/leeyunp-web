專案 -XR 白內障模擬系統

這個專案的目標，是透過 XR 場景與多模態回饋，模擬白內障患者在真實環境中的行走體驗，讓使用者更具體感受到導航回饋與沉浸式互動設計的差異。它補強了我在研究、互動設計、系統整合與跨域協作上的完整能力。

問題內容

這一區先說清楚專案想模擬什麼，讓讀者理解它不是單純做裝置，而是在處理一個體驗設計與感知理解問題。

專案背景

白內障患者在真實環境中的移動，不只是視覺模糊而已，還會連帶影響對方向、障礙與導航回饋的理解。因此，我們希望用 XR 與即時回饋設計，把這種感知落差轉成可被體驗與研究的互動情境。

核心痛點

  1. 一般人很難具體理解白內障視角下的移動困難。
  2. 導航提示若只依賴單一感官，沉浸感與理解度有限。
  3. 要讓系統在真實互動裡即時判斷並回饋，整合難度高。
  • Immersive Experience
  • Assistive Navigation
  • Multi-modal Feedback

功能與系統

把 XR 場景、感測與回饋模組分開說明，讀者會更容易看出這是一個完整互動系統。

主要功能

  1. 以 Unity 建立 XR 場景，模擬視覺限制。
  2. 結合 Meta 頭盔與 Unity 建立沉浸式互動實驗環境。
  3. 以 Arduino 穿戴式系統在腰部或手臂提供外力控制與觸覺回饋。
  4. 在 Unity 場景發生碰撞時，即時偵測方向並做反方向拉回。
  5. 讓整個互動回饋流程保持連續、即時且自然。

系統設計思路

整體流程是感測、判斷、回饋的 real-time loop。感測端取得碰撞或環境資訊後，系統要即時判斷當前情況，再透過觸覺與音訊回饋引導使用者，確保互動不是分離的，而是連續的體驗流。

專案成就

這裡不一定只放比賽名次，也可以強調這個專案在互動研究與系統整合上的成果。

具體成果

  1. 完成 XR 場景與感測裝置的整合原型。
  2. 建立視覺限制、碰撞偵測、方向判斷與穿戴式外力回饋的完整互動流程。
  3. 把輔助導航議題轉成可體驗、可展示的互動系統。
這個成果代表什麼 這代表我不只會做軟體頁面或資料系統，也具備處理硬體互動、即時回饋與人機互動情境的能力。
